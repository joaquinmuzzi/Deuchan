Settings

For a Chrome profile you use only for German. It is set for this profile alone, and asks to read the sites you visit, to find their videos. Any tab that plays sound counts too.

Count streaming sites

Counts what plays in German, from the audio the player says is playing. Each site asks for access to its own pages only.

Your data

Save your history to a file, and open it in another browser or another install of Inputly. The file stays on your computer. "Export CSV" saves your time per day and item in the format Kechimochi imports (Activity Logs), which any spreadsheet opens too.

Import data

Replace deletes the history here and keeps the one in the file. Merge keeps both: for each day the larger time, and the settings already here. The immersion profile, streaming sites and Send to Mosaik are not in the file: turn them on again here.

Videos and reading

    Send to Mosaik

    Off

    Mosaik is an app that puts together how you learn languages, on this computer or on your own server. Inputly can send it your time per day and when you watched which video (its id and title), only to the address you write here.

    Only for a Mosaik server (an https address): make one for this computer in Mosaik, Fuentes → Dispositivos. It stays in this browser and only goes to that address.

    Send to Kechimochi

    Off

    Kechimochi is a desktop immersion tracker. Inputly can send it your minutes per day for each video, sound and reading (their titles and sites), only to the address you write here. Turn on its HTTP API in its profile tab first; Allowed Browser Origins can stay empty.

    On this computer, or another one on your home network (turn on LAN mode in Kechimochi). Use either this or the CSV export for the same days, not both: each would add the time again.
